用一个场景穿过关键边界

  1. 用户从明确入口提交意图。
  2. 核心 owner 执行正常路径。
  3. 安全、取消或恢复条件触发显式分支。
  4. 持久事实更新，投影层发布可观察结果。
  5. 聚焦测试验证正常路径和失败路径。

> slice and partial G41 closure

**Goal:** Make Ctrl+T present logical WorkItems and exact execution
generations in one deterministic, textually distinguished list while keeping
selection bound only to exact row identity across refresh, reorder, removal,
empty snapshots, and resize.

**Architecture:** `TaskExplorerPanel` remains the Module and keeps its existing
`Show`, `Refresh`, `HandleKey`, and `Render` Interface. A panel-local mixed-row
projection is the Seam: it appends the engine-sorted WorkItems followed by the
engine-sorted executions, assigns one exact mutually exclusive identity to
each row, and feeds the existing selection restoration and bounded rendering
paths. This deepens the Module without adding an engine ordering contract,
caller flags, or a new public Interface.

**Tech Stack:** Go 1.26.5, `TaskExplorerSnapshot`, Bubble Tea v2 rendering,
standard Go tests, the race detector, and repository Makefile gates.

## Frozen Contract

- Execute only P47.4; do not add P47.5 filter/focus behavior or P47.6/P47.7
  detail tabs and lazy I/O.
- Adoption is `project-native`: one Ctrl+T mixed list uses WorkItems first and
  exact execution generations second. Each group preserves the current engine
  snapshot order; no cross-kind runtime comparator or linkage inference is
  introduced.
- Ctrl+T opens the mixed projection. Existing logical-only and execution-only
  sections may remain private compatibility fixtures, but are not the Ctrl+T
  observable.
- Every selectable row includes textual `WorkItem` or `Execution` identity in
  every responsive layout; color, glyph, title, owner, thread, and row position
  are never the only kind or identity signal.
- A WorkItem identity is exactly `(BoardID, WorkItemID)`. An execution identity
  is exactly `(AgentID, Generation)` with a positive generation. Partial,
  mixed-kind, title-, owner-, or ThreadID-derived identities are invalid.
- Refresh and search first restore the exact identity. If it disappears, the
  prior cursor is clamped to the new list, which selects the nearest visible
  row deterministically. An empty projection clears cursor, selection, detail,
  and offset.
- Resize and rendering may adjust viewport offset but never change the selected
  identity or cursor.
- WorkItem rows continue to reject execution action keys locally. Execution
  actions keep the exact P47.1/P47.3 request, declaration, correlation, and
  navigation paths; no action eligibility is inferred by the panel.
- Rendering remains bounded and I/O-free in narrow, compact, standard, and
  wide layouts. Existing Ctrl+B, `/team`, picker, engine snapshot, persistence,
  ACP, and public wire behavior remain unchanged.
- Final code verification uses `make fmt`, `make lint`, `make test`, and
  `make build`; closeout also uses `make docs-check`, migration queue and
  manifest checks, and `git diff --check`.

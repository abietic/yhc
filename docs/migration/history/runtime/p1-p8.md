## P4: Hook and Service Lifecycle Depth

**State at closeout:** complete. Synchronous shell hooks now terminate the
whole process tree with a bounded graceful-to-forced escalation, distinguish
timeout from parent cancellation, and preserve non-blocking failures as
structured attachments. Exit code 2 and explicit `continue=false` retain their
blocking semantics. HTTP hooks remain single-attempt and timeout-bounded, which
matches the reference and avoids replaying side-effecting POST requests.
Plugin commands refresh atomically. Asynchronous shell hooks are owned by each
engine executor, publish bounded running/completion events to TUI and ACP,
inject results exactly once at a model boundary, and preserve exit-code-2
`asyncRewake` without re-entering user-prompt hooks.
Interactive TUI, plain REPL, and ACP engines now own coalesced session-memory,
durable extraction, and auto-dream jobs; close and resume cancel/join or rebind
that ownership. Auto-dream uses persisted transcript evidence, scan throttling,
and an exclusive lock. Shared memory loads before mutation, merges concurrent
writers, and ranks against the latest user query. TUI welcome tips rotate from
project-local persisted history while first-run guidance remains pinned.

Acceptance criteria:

- [x] Specify shell-hook timeout and termination escalation.
- [x] Distinguish recoverable hook failure from session-aborting failure.
- [x] Verify HTTP hooks are single-attempt and timeout-bounded; do not add
  automatic retries for side-effecting POST hooks when the reference has none.
- [x] Route async shell completion/error through executor-owned lifecycle,
  bounded shutdown, runtime/TUI/ACP projection, and `asyncRewake` continuation.
- [x] Improve auto-dream scheduling, memory relevance ranking, and suggestion
  rotation only with measurable long-session acceptance tests.
- [x] Add plugin-contributed command discovery and hot-reload as one plugin
  lifecycle slice.

P4 lifecycle implementation evidence:

## P5: MCP and Subagent Isolation

current engine scope. Owner close cancels and joins Agent generations before
disconnecting MCP. HTTP transports use Go's proxy-aware default transport and

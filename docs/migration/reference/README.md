## Classification notes

- Runtime reports compare architecture, capability, and convergence evidence.
- Parity reports compare a specific compatibility behavior; they do not make
  parity the project objective.
- TUI reports are research snapshots; current TUI architecture and contracts live
  in [`../../architecture/tui/`](../../architecture/tui/).
- New comparative reports should end with an explicit `preserve`, `adapt`,
  `combine`, `project-native`, `reject`, or `defer` recommendation.

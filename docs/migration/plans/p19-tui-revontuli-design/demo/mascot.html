Eno, the aurora fox

Finnish folklore says the northern lights — revontulet, "fox fires" — are sparks swept into the sky by a fox's tail. Eno is that fox: a 15×6 block-art cub in three foreground tones, replacing the ported Clawd mascot (mascot.go). The proportions follow the fox emoji 🦊: big two-row ears with dark tips, large round wide-set eyes — and the fox-versus-cat cue: the cheek row flares out to become the widest row of the face (15 cells under a 13-cell head), then the chin tucks back to 9, with a round nose sitting on the cheek line.

Rendering rules

  • Two tones per theme: enoBody, enoOutline — added to the palette struct, so every theme (incl. Daybreak and ANSI fallbacks) retones the fox automatically. The face is not a palette hex.
  • Foreground colors only. Never set a background behind mascot cells. Face cells (eyes ●, nose ●) render with terminal-default styling as negative space — the TUI does not own the terminal's global background, so the face must not assume one. (The mock paints enoFace only because this page owns its demo background.)
  • Grid is fixed 15 wide × 6 tall; poses only swap eye cells, ear-adjacent sparkle row, and trailing z — so tests can pin exact strings exactly like mascot_welcome_test.go does today.
  • Animations: 60ms frames for click/celebrate (current MascotTick timing), 180ms blink, jittered 3–5s glance. Idle blink/glance needs a new gated timer (pattern: ensureSpinnerTick, app.go:4496) that runs only while the welcome state is visible — today's ticks fire only during click-triggered sequences (app.go:882-887). All motion off under reduced-motion.
  • Small-space fallback: below 57 cols the mascot hides (current behavior); the ✦ spark is the always-available identity.
  • Light terminals: the negative-space face inherits the terminal's own background by construction — no per-theme face value exists.
Naming: the fox answers to Eno. In code, the pose map stays map[MascotPose]poseSegments; only segment strings, the render size (9×3 → 15×6), and the color fields (clawdBody/clawdBg → enoBody/enoOutline, face = terminal default) change. See README §8.

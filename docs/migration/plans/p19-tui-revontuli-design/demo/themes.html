Themes & tokens

Two truecolor themes plus a 16-color ANSI fallback, all driven by one semantic token set. The token architecture in theme.go is kept — palettes, semantic mapping, EINO_THEME override — only the values (and three new mascot fields) change.

The aurora ramp

One gradient, three anchor colors. Used only where the brand should glow: the welcome title, the spinner shimmer sweep, and focused/active accents. Everything else uses flat tokens.

The real TUI does not paint the user's global terminal background, so the check is a design reference rather than a universal terminal WCAG guarantee.

What stays the same

  • Theme resolution order: EINO_THEME env → config → auto-detect (theme.go:229-251).
  • Palette → Styles assembly (theme.go:254); consumers keep reading semantic styles.
  • The six-slot theme registry grows: polar-night (new default), daybreak, ±ansi. Legacy dark/light names alias to the new pair for one release, with aubergine/snowy re-evaluated or retoned.

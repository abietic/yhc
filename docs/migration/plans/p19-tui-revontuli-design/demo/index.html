Revontuli / eino-agent TUI redesign

Revontuli is Finnish for the aurora — folklore says a fox sweeping snow with its tail lit the northern lights. This proposal replaces the borrowed Claude Code identity (orange #D77757, the Clawd mascot, the ✻ glyph) with an aurora gradient system and a new mascot: Eno, the aurora fox.

Identity at a glance

✦ The spark

Agent mark. Prefixes assistant output, anchors the spinner, closes the wordmark. ✦ filled = agent, ✧ outline = system.

Eno, the aurora fox

15×6 block-art mascot in three foreground tones. Blinks, looks around, celebrates shipped work. No background fills — terminal-safe.

Aurora ramp

One gradient: teal #4FE3C1 → sky #7CD4F7 → violet #A78BFA. Used with restraint: welcome title, shimmer sweep, focus states.

Mode-reactive chrome

The composer border carries the mode color — teal default, sky plan, amber shell, red yolo. Mode is visible where your hands are.

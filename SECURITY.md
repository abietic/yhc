# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
https://github.com/abietic/yhc/security/advisories/new.

Do not open a public issue for an unpatched vulnerability. Include enough
information to reproduce and assess the issue without including credentials,
tokens, private repository content, or other sensitive data.

## Handling

Maintainers will acknowledge a report, assess scope and impact, and coordinate
private remediation before publishing details. Do not expect a public issue,
security contact email, or a disclosure timetable to substitute for the private
advisory process.
